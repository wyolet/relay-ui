# Contributing to relay-ui

Thanks for your interest in contributing. relay-ui is the operator admin UI
for [Wyolet Relay](https://github.com/wyolet/relay) — a static React SPA that
is embedded into the Relay Go binary via `//go:embed` and served at `/ui/`.
This guide covers how to build, run, and submit changes, plus the load-bearing
rules every change must obey.

## Prerequisites

- **[Bun](https://bun.sh)** (package manager + test runner)
- A running **Relay** control plane to develop against — the standalone image
  serves it on `http://localhost:8081` (`:8080` is the data plane):
  ```bash
  docker run -p 8080:8080 -p 8081:8081 wyolet/relay:standalone
  ```

## Getting started

```bash
git clone https://github.com/wyolet/relay-ui
cd relay-ui
bun install
bun run dev          # Vite dev server on http://localhost:5140
```

The dev server proxies `/api` and `/config.json` to the control plane at
`http://localhost:8081`. Override the target:

```bash
RELAY_CONTROL_TARGET=http://localhost:8081 bun run dev
```

## Build & checks

```bash
bun run build        # production bundle → dist/
bun run ci           # typecheck + lint + test (run before pushing)
```

`bun run ci` is exactly what CI runs on every push and PR. Keep it green.

## API types

The typed API client is generated from Relay's OpenAPI spec — never hand-edit
`src/api/types.gen.ts`:

```bash
make gen                                       # default: http://localhost:8081/api
RELAY_URL=http://localhost:8081/api make gen   # custom control-plane URL
```

Commit the regenerated file alongside the change that needs it.
`src/routeTree.gen.ts` is likewise generated by the router plugin — don't edit
it by hand.

## Codebase rules (non-negotiable)

The full set lives in [`CLAUDE.md`](CLAUDE.md), which doubles as the
architectural orientation doc. The ones a PR is most likely to trip on:

1. **Components render strings.** No fetching, mutations, or derived business
   state inside a `.tsx`. Logic lives in `useXThing()` / `useXForm()` hooks.
2. **`.tsx` files never import `@/api/...` or `@/stores/...` directly** —
   wrap them in a domain hook and import that.
3. **State has exactly four homes:** server state → TanStack Query
   (`queryOptions`), forms → TanStack Form + zod (in a `useXForm` hook),
   persisted/shared client state → zustand, component-local ephemeral → `useState`.
   Never `useEffect` for fetching.
4. **Semantic tokens, not raw colors.** `bg-card`, `text-muted-foreground`,
   `border-border`, … — never `bg-white dark:bg-neutral-900`.
5. **Never escape the type system.** No `any`, no `as unknown as T`, no
   `@ts-ignore`, no non-null `!` to silence errors. Derive types from the
   OpenAPI schema.
6. **Domain folders own their components, hooks, and contexts together.**
   Dependency direction is downward; no circular imports between domains.

Biome owns formatting and lint (`src/components/ui/**` and `src/styles/**` are
intentionally ignored — vendored shadcn and Tailwind directives).

## Pull request workflow

- **Branch off `main`.** One logical change per PR.
- **Run `bun run ci`** before pushing.
- **Include screenshots** for any visible UI change.
- **Keep commits focused** with clear messages. Reference issues where relevant.
- **Comments:** default to none. Write one only when the *why* is non-obvious.

## Releases

Releases are cut from a `v*` git tag (see the `release` target in the
`Makefile`). CI builds the project and uploads a `relay-ui-vX.Y.Z.tar.gz`
asset, which the main `wyolet/relay` repo pins and embeds at build time.

## Reporting bugs / requesting features

Open an issue using the templates. For security issues, **do not open a
public issue** — see [`SECURITY.md`](SECURITY.md).
